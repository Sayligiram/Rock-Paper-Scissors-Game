Rock Paper Scissors Game

A mini project, Rock Paper Scissors game built using Python.

About the Project

This is a simple command-line game where the user plays Rock Paper Scissors against the computer. The computer randomly selects one of the three choices, and the winner is decided based on the game rules.

Features
- User can choose Rock, Paper, or Scissors
- Computer makes a random choice
- Displays both choices
- Determines the winner
- Tracks the score
- Allows the user to play multiple rounds
- Handles invalid input
- Shows the final score

using the topics
- Python
- Random module
- Conditional statements
- Loops
- Lists
- Variables
- User input

How to Run
 Run the program,
 Enter "rock", "paper", or "scissors" when printed

Game Rules
- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choices result in a tie

Example
# ROCK PAPER SCISSORS GAME 

Enter rock, paper or scissors: rock
You chose: rock
Computer chose: scissors
You win!

Your score: 1
Computer score: 0
